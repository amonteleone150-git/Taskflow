🚀 TASKFLOW v2.0.0

QUESTO è IL LINK DI TASKFLOW: https://ytaskflow.netlify.app/

The official release of TASKFLOW v2.0.0 is here!

TASKFLOW is a modern, responsive task management application designed to help you organize your daily activities, manage your schedule, and stay productive.

With version 2.0.0, TASKFLOW introduces a major upgrade, including user authentication, personal dashboards, and database integration.

✨ What's New in v2.0.0

✅ User Authentication — Create an account, register, and securely log in to access your personal workspace.

👤 Personal Dashboard — Every user has their own personalized dashboard to manage tasks and organize daily activities.

🗄️ Database Integration — User accounts, tasks, and related data are now managed through a database.

📋 Task Management — Create, edit, organize, and manage your daily tasks.

📅 Calendar & Agenda — Keep track of your activities, deadlines, and schedules.

🔎 Advanced Filters — Find and organize tasks more easily with filtering options.

📱 Responsive Design — Optimized for desktop, tablet, and mobile devices.

🎨 Redesigned User Interface — A modern visual style, improved usability, and a smoother user experience.

👤 Personal Dashboard

One of the biggest improvements in TASKFLOW v2.0.0 is the introduction of personal user accounts.

Users can now:

Register and create their own account.
Log in and access their personal workspace.
Manage their own tasks and activities.
Access a personalized dashboard.
Keep their data associated with their account through database integration.

📌 What's Changed?

TASKFLOW v1.0.0 relied on browser localStorage to store tasks and related information.

With v2.0.0, the application introduces a new architecture featuring authentication, personal dashboards, and database integration.

This transforms TASKFLOW from a simple local task manager into a personalized task management platform.

🧪 How to Run TASKFLOW Locally
Prerequisites

Make sure Node.js is installed on your computer.

Installation and Setup
Clone the repository:
bash
git clone https://github.com/amonteleone150-git/Taskflow.git

Navigate to the application folder:
bash
cd Taskflow/my-app

Install dependencies:
bash
npm install

Configure your environment variables according to the database and authentication configuration.
Start the development server:
bash
npm run dev

Open your browser and navigate to:
text
http://localhost:3000

🔐 Authentication & Database
