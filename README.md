🚀 TASKFLOW v1.0.0

The first official release of TASKFLOW!

TASKFLOW is a responsive task manager designed to help you organize your daily activities in a simple, intuitive, and efficient way.

✨ Features
✅ Task Management — Create, organize, and manage your daily tasks.
📅 Calendar & Agenda — Keep track of your activities and schedule.
🔎 Filters — Find and organize tasks more easily.
📱 Responsive Design — Optimized for desktop and mobile devices.
💾 Local Data Storage — Tasks and related data are stored locally in your browser using localStorage.
🎨 Redesigned UI — A modern visual style and an improved user experience.
🎨 Redesigned User Interface

This release introduces a completely redesigned user interface, featuring a more modern look, improved usability, and a smoother experience across different devices.

📌 Notes

This version uses browser localStorage to store tasks and related data locally.

Database integration, user authentication, and cloud synchronization are not currently included but may be considered for future releases.

🧪 How to Run TASKFLOW Locally
Prerequisites

Make sure Node.js is installed on your computer.

Installation and Setup
Clone or download the repository.
Open a terminal and navigate to the project directory.
Enter the application folder:
cd my-app

Install the dependencies:
npm install

Start the development server:
npm run dev

Open your browser and navigate to:

http://localhost:3000
